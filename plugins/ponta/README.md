# Ponta for Claude

Ponta lets Claude do real work on your own Windows PCs. Claude can read and sort files, run commands, use desktop apps, work in a web browser and read or draft email on the PCs you add. Anything that could cause harm waits for you to approve it.

## What you get

- The Ponta connector, at https://mcp.ponta.ai/mcp. It is the same connector as Ponta in Claude's connector list, so you see one set of tools.
- A skill called using-ponta. It tells Claude how to use the Ponta tools well, for example to check which PCs are online first and to ask before it changes anything.
- Four commands: check-setup, fill-pdf-form, practice-approval and phone-to-pc. In chat they work as skills. In Claude Code you type them, for example /ponta:check-setup.

## How to use it

1. Install Ponta on a Windows 10 or 11 PC from https://ponta.ai and add the PC to your account.
2. Add this plugin in Claude, then open its Connectors tab and connect Ponta. Sign in with your Ponta account.
3. Ask Claude: "Check my Ponta setup and show me what you can do."

Help: https://ponta.ai/help

## What data it sends

Your requests and the results go between Claude and your own PCs through mcp.ponta.ai. Ponta does not keep your files, mail or screen. It keeps your sign-in email, your PCs, a short log of what Ponta did and your plan. The plugin itself stores nothing. The full privacy notice is at https://ponta.ai/privacy.
